# فایل‌های پروژه حبیب دستیار

این ZIP شامل فایل‌های پروژه اندروید است؛ فایل گردش‌کار GitHub Actions را عمداً داخل ZIP نگذاشته‌ام، چون گفتی آن فایل را قبلاً در GitHub ثبت کرده‌ای.

## بارگذاری در GitHub

1. ZIP را استخراج کن.
2. وارد مخزن GitHub خودت شو.
3. همه فایل‌ها و پوشه‌های استخراج‌شده را در ریشه همان مخزن بارگذاری کن.
4. پوشه‌ها باید همین ساختار را داشته باشند؛ به‌خصوص `app` و فایل‌های `settings.gradle` و `build.gradle`.
5. بعد از بارگذاری، از بخش Actions گردش‌کار Build APK را اجرا کن.
6. پس از موفقیت، از بخش Artifacts فایل `Habib-Assistant-APK` را دریافت کن.

## اتصال به سرور

این نسخه به نشانی `POST /chat` درخواست می‌فرستد و JSON با فیلد `message` ارسال می‌کند. پاسخ را از فیلد `answer` یا `response` می‌خواند. این فقط قرارداد اولیه است؛ اگر API پروژه فعلی Habib-AI تو مسیر یا قالب دیگری دارد، باید آن را با کد برنامه هماهنگ کنیم.

این نسخه اولیه فقط ورود متن/گفتار و ارسال به سرور و خواندن پاسخ را دارد. اجرای فرمان‌های گوشی و ارسال پیامک هنوز پیاده‌سازی نشده است.
